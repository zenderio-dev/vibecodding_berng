# Запуск MCP Серверов в VS Code

## Способ 1: Использовать встроенный отладчик VS Code (РЕКОМЕНДУЕТСЯ)

1. **Откройте проект в VS Code:**
   ```bash
   code .
   ```

2. **Перейдите на вкладку "Run and Debug":**
   - Нажмите `Ctrl+Shift+D` или найдите иконку Run на левой панели

3. **Выберите конфигурацию запуска:**
   - В выпадающем меню выберите **"Start All MCP Servers"**
   - Нажмите зеленую кнопку ▶ или нажмите `F5`

4. **Серверы запустятся в интегрированном терминале:**
   - MCP1 будет работать на `http://localhost:3001`
   - Context7 будет работать на `http://localhost:3002`

5. **Для остановки:** Нажмите красную кнопку ◼

---

## Способ 2: Запуск отдельных серверов

Если нужно запустить только один из них:

1. В "Run and Debug" выберите:
   - **"Start MCP1 Server"** - для локального сервера
   - **"Start Context7 Client"** - для клиента context7

2. Нажмите F5 или кнопку запуска

---

## Способ 3: Запуск через команду в терминале

Если хотите запустить все серверы в одном терминале:

```bash
npm start
```

Или отдельно:

```bash
npm run start:mcp1
npm run start:context7
```

---

## Проверка что серверы работают

После запуска откройте в браузере:

- **MCP1:** http://localhost:3001/health
- **Context7:** http://localhost:3002/health

Должны увидеть JSON с `"status": "healthy"`

## Мониторинг в реальном времени

Когда серверы запущены через VS Code:

1. Откройте **Debug Console** (`Ctrl+Shift+Y`) - выведет логи
2. Или используйте **Integrated Terminal** (`Ctrl+~`) - выведет stderr/stdout
3. Серверы автоматически перезагружаются при изменении кода (если запущены с `--watch`)

---

## Проблемы

### "Порты уже используются"
```
EADDRINUSE: address already in use :::3001
```
Убийте процессы Node.js:
- На Windows: Откройте Task Manager, найдите node.exe и завершите процесс
- Или переопределите порты через переменные окружения в launch.json

### "Расширение MCP не найдено"
Убедитесь что в VS Code установлено какое-то расширение для поддержки MCP или других языков для debugginga Node.js.
